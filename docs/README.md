# Stecyk3D documentation

Stecyk3D is a renderer, written in Rust, that draws Bryce 3.0, 3.1 and 5.0 scenes, with a Blender add-on ("Stecyk3D for Blender") that lets you render your Blender scenes with it. The renderer is MIT-licensed, the add-on GPL-3.0-or-later. **Experimental.**

| If you want to... | Read |
|---|---|
| install it, render from Blender, fix a problem | [User manual](manual/README.md) |
| understand the code or extend it | [How it works](how-it-works/README.md) |

Names used in these pages: the Rust crate is `stecyk3d`; the programs are `stecyk3d-render`, `stecyk3d-extract` and `stecyk3d-cases`; the Blender add-on's module is `stecyk3d`.
